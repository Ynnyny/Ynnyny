05 / FEATURED SYSTEM

TGLMT

OPENGL 4.6 CORE → METAL

A rendering layer for running OpenGL 4.6 Core code on Metal, aimed at the Minecraft Java boot path on iOS. It uses GL dispatch and a dedicated core, without MoltenVK or ANGLE.
